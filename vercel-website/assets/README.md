# Assets Directory

Place your logo and other assets here.

## Required Assets

- `logo.svg` or `logo.png` - Company logo (recommended size: 200x200px or larger)
- Any other images, icons, or media files

## Logo Requirements

The logo should be:
- SVG format (preferred) or PNG with transparent background
- High resolution for crisp display
- Optimized for web (compressed)

The header and footer will automatically fallback to PNG if SVG is not available.
